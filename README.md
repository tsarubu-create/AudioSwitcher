# AudioSwitcher

Windows 11 の PC で鳴っている音を、同じ Wi-Fi にいる Android 端末へ転送して聴くための自分用アプリ。

- PC 側: C# / .NET 10（タスクトレイ常駐）
- Android 側: Kotlin / Jetpack Compose / Media3

構成と決めごとは [docs/構成.md](docs/構成.md) を参照。

## PC 側（試作）

### 要るもの

- Windows 11
- .NET 10 のランタイム（Desktop と ASP.NET Core）。.NET 10 の SDK が入っていれば足りる。

### 動かし方

1. `AudioSwitcher.exe` を起動する。タスクトレイにアイコンが出る（Windows 11 では、タスクバーの右端の「^」の中に隠れることがある。白い四角い窓の形の汎用のアイコンで、マウスを重ねると「AudioSwitcher - 待ち受け中」と出る）。
2. 初回は Windows のファイアウォールの許可を求める画面が出る。同じ Wi-Fi の Android から繋ぐには「プライベート ネットワーク」を許可する。
   - Wi-Fi のネットワークの種類が「パブリック」になっていると止められやすい。「設定 → ネットワークとインターネット → Wi-Fi → 繋いでいるネットワーク」で「プライベート ネットワーク」にする。
3. トレイのアイコンを右クリックすると、状態（待ち受け中／送信中）と、端末に入れる接続先（`<IP>:48100`）が出る。押すとコピーする。
4. 初めての端末はペアリングする。端末で「ペアリングを始める」を押すと、PC の画面の手前に2桁の数字が出るので、端末で同じ数字を選ぶ（2分で無効）。
5. 端末で「再生」を押すと、音を取り始めて流す。端末が止めると止める。
6. 終えるときは、トレイのメニューの「終了」。

### ペアリング

詳しい決まりは [docs/構成.md](docs/構成.md) の 2.3。

- 1回外れたら数字を作り直す。**続けて2回外れたら24時間ペアリングを受け付けない**（アプリを起動し直しても続く）。持ち主が選び間違えたときは、トレイの「受け付けない状態を解く」ですぐに解ける。
- ペアリング済みの間は、別の端末からのペアリングを受け付けない。端末を替えるときや手放したときは、トレイの「ペアリングを解除」を押す（古い端末の鍵では繋げなくなる）。
- ペアリングの状態は `%LOCALAPPDATA%\AudioSwitcher\pairing.json` に保存する（鍵そのものではなく、鍵のハッシュだけ）。

- ポートは起動の引数で変えられる: `AudioSwitcher.exe --port 48200`
- ログ: `%LOCALAPPDATA%\AudioSwitcher\logs`（トレイの「ログのフォルダを開く」）

### 試作の制約

- 通信は暗号化しない HTTP。同じ Wi-Fi で通信を盗み見できる人には鍵が見える（自分用・家庭用として許している）。
- トレイのアイコンは Windows の汎用のもの。

### 開発

```
cd pc
dotnet build
dotnet test
```
