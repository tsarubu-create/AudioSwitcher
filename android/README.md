# Android 側（試作）

PC 側（`pc/`）が流す音を受けて再生する。画面を消しても再生を続ける。

## 使い方

1. PC 側の `AudioSwitcher.exe` を起動しておく。
2. アプリを開き、PC の IP とポートを入れる（例: `192.168.1.5:48100`。ポートを省くと 48100）。PC の URL は、PC のトレイのメニューに出る。
3. 「再生」を押す。画面を消しても再生が続き、通知とロック画面から止められる。
4. PC との接続が切れたら、1秒から倍々（上限15秒）の間をあけて繋ぎ直す。「停止」を押すまで続ける。

## 試作の制約

- ペアリング（`docs/構成.md` の 2.3）はまだ無い。
- アイコンは Android の汎用のもの。

## ビルド

環境は `docs/開発環境.md` を参照。

```
cd android
./gradlew :app:testDebugUnitTest :app:assembleDebug
```
