# Android 側（試作）

PC 側（`pc/`）が流す音を受けて再生する。画面を消しても再生を続ける。

## 使い方

1. PC 側の `AudioSwitcher.exe` を起動しておく。
2. アプリを開き、PC の IP とポートを入れる（例: `192.168.1.5:48100`。ポートを省くと 48100）。PC の接続先は、PC のトレイのメニューに出る。
3. 初めての PC とは、「ペアリングを始める」を押し、PC の画面に出た2桁の数字と同じものを5つの候補から選ぶ。合えば鍵を受け取って保存する（Android Keystore で暗号化）。
4. 「再生」を押す。画面を消しても再生が続き、通知とロック画面から止められる。
5. PC との接続が切れたら、1秒から倍々（上限15秒）の間をあけて繋ぎ直す。「停止」を押すまで続ける。

- PC の IP が変わっても、接続先を書き換えるだけでよい（鍵は残す）。
- PC 側で「ペアリングを解除」すると、次に繋いだときに PC が鍵を断る。アプリは鍵を捨てて止まり、解除された旨を出してペアリングの画面に戻る。

## 試作の制約

- アイコンは Android の汎用のもの。

## ビルド

環境は `docs/開発環境.md` を参照。

```
cd android
./gradlew :app:testDebugUnitTest :app:assembleDebug
```
