# 画面

Android 側と PC 側の画面の決めごと。Android 側の画面は、デザインの Skill（frontend-design）を通して設計した。

## 方針

- **題材**: PC の音を、線の代わりに Wi-Fi で端末へ引く自分用の道具。
- **画面のいちばんの役目**: いま繋がっているか・どのくらい聴いているかがひと目で分かること。ペアリングのときに、PC の右下のポップアップと同じ数字を迷わず選べること。
- **目立たせるのは1か所だけ**: PC から端末へ引いた「線」。線そのものが状態を表す。ほかは静かにする（カードや影で区切らず、線と余白で区切る）。
- PC の右下のポップアップと同じ色の系統にそろえ、PC と端末で1つの道具に見えるようにする。

## 色

端末の設定に合わせて、白基調（ライト）とダークを切り替える（`ui/Theme.kt`）。

| 名前 | ライト | ダーク | 役目 |
|---|---|---|---|
| 地 | `#FFFFFF` | `#161B21` | 背景 |
| 墨 | `#1F2328` | `#E6EDF3` | 本文・数字 |
| 鉛 | `#57606A` | `#9AA4AE` | 補足の文 |
| 罫 | `#D0D7DE` | `#30363D` | 止まっている線・枠 |
| 信号 | `#0969DA` | `#4C9AFF` | 再生中の線・主なボタン・残り時間 |
| 警告 | `#CF222E` | `#FF7B72` | 繋がらない・知らせ |

- ダークの地は、真っ黒にもありがちな「ほぼ黒」にもせず、少し青みのある色にした（信号の青が浮きすぎないように）。
- 状態は色だけに頼らず、文字（「再生中」など）でも出す。

## 文字

- 書体は端末の標準の日本語の書体（新しい書体は入れない）。
- 大きさは 28 / 20 / 16 / 13 の4段だけ。経過時間は 28、題名と候補の数字は 20、本文とボタンは 16、補足は 13。
- 経過時間と候補の数字は**等幅の数字**（`tnum`）にして、桁が揺れないようにする。

## PC から端末への線（`ui/RouteLine.kt`）

| 状態 | 線 |
|---|---|
| 止まっている | 灰色（罫）の細い実線 |
| 繋いでいる・繋ぎ直している | 青（信号）の破線 |
| 再生中 | 青（信号）の実線の上を、小さな点が 2.4 秒で左から右へ流れる |
| 繋がらない（繋ぎ直しを待っている） | 赤（警告）の破線 |

- 動くのは再生中の点だけ。端末の設定で動きを切っている（アニメーションの速度が 0）ときは、点を流さず真ん中に止めて出す。

## 再生の画面

```
AudioSwitcher

PC ──────●────── この端末
192.168.11.5:48100

再生中
12:34

[          停止          ]   ← 再生中は枠線だけ、止まっているときは青い「再生」
接続先を変える
```

- **経過時間**（利用者と決めた）: 「再生」を押してから数える。繋ぎ直している間も数え続け、「停止」で消える。1時間未満は「分:秒」（5:07、23:45）、1時間以上は「時:分:秒」（1:23:45）。秒の境目ちょうどに書き換える。
  - 時刻は単調な時計（`SystemClock.elapsedRealtime`）で、再生サービスが「再生を押した時刻」を記録する（`PlaybackStartStore`）。画面を閉じて開き直しても、続きから出る。
- 接続先は普段は小さく出すだけで、「接続先を変える」を押したときだけ入力欄を出す。保存した接続先は、次に再生したときから使う（鍵は残す。docs/構成.md の 2.3）。

## ペアリングの画面

```
AudioSwitcher

（PC で解除されたときの知らせ。赤）

接続先（PC の IP:ポート）
[ 192.168.11.5:48100     ]

PC に出た数字と同じものを選んでください。
┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐
│12│ │47│ │80│ │03│ │66│
└──┘ └──┘ └──┘ └──┘ └──┘
残り 1:52
```

- 候補は同じ幅の四角いタイルを横一列に並べる。
- 残り時間は、PC のポップアップと同じく 2:00 から減る（外れて数字が作り直されたら、また 2:00 から）。
- 外れ・時間切れ・受け付けない状態などの知らせは赤（警告）で出し、PC で何をすればよいかを書く。
- 赤い知らせは同時に1つだけにする。「PC とのペアリングが解除されました」は、「ペアリングを始める」を押した時点で役目を終えるので消す（そのあとの外れなどの知らせと2つ並ばないように）。

## PC 側

常に出ている窓は無い。トレイのアイコンとメニューのほか、ペアリングの間だけ、画面右下に白基調のポップアップで数字を出す（docs/構成.md の 2.3）。
