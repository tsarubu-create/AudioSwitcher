# 画面

Android 側と PC 側の画面の決めごと。Android 側の画面は、デザインの Skill（frontend-design）を通して設計した。

## 方針

- **題材**: PC の音を、線の代わりに Wi-Fi で端末へ引く自分用の道具。
- **画面のいちばんの役目**: いま繋がっているか・どのくらい聴いているかがひと目で分かること。ペアリングのときに、PC の右下のポップアップと同じ数字を迷わず選べること。
- **目立たせるのは1か所だけ**: PC から端末へ引いた「線」。線そのものが状態を表す。ほかは静かにする（カードや影で区切らず、線と余白で区切る）。
- PC の右下のポップアップと同じ色の系統にそろえ、PC と端末で1つの道具に見えるようにする。

## 色

白基調（ライト）とダークの2つ（`ui/Theme.kt`）。**再生の画面（ペアリングの画面も）の右上の「ダーク」の切り替え**で選ぶ（利用者と決めた。2026-10-21）。一度も選んでいなければ端末の設定に合わせ、選んだらその色を覚えて、端末の設定には合わせなくなる。上の時計などの帯（ステータスバー）の文字の色も、選んだ色に合わせる。

| 名前 | ライト | ダーク | 役目 |
|---|---|---|---|
| 地 | `#FFFFFF` | `#161B21` | 背景 |
| 墨 | `#1F2328` | `#E6EDF3` | 本文・数字 |
| 鉛 | `#57606A` | `#9AA4AE` | 補足の文 |
| 罫 | `#D0D7DE` | `#30363D` | 止まっている線・枠 |
| 信号 | `#0969DA` | `#4C9AFF` | 再生中の線・主なボタン・残り時間 |
| 警告 | `#CF222E` | `#FF7B72` | 繋がらない・知らせ |

- ダークの地は、真っ黒にもありがちな「ほぼ黒」にもせず、少し青みのある色にした（信号の青が浮きすぎないように）。
- 状態は色だけに頼らず、文字（「再生中」など）でも出す。

## 文字

- 書体は端末の標準の日本語の書体（新しい書体は入れない）。
- 大きさは 28 / 20 / 16 / 13 の4段だけ。経過時間は 28、題名と候補の数字は 20、本文とボタンは 16、補足は 13。
- 経過時間と候補の数字は**等幅の数字**（`tnum`）にして、桁が揺れないようにする。

## PC から端末への線（`ui/RouteLine.kt`）

| 状態 | 線 |
|---|---|
| 止まっている | 灰色（罫）の細い実線 |
| 繋いでいる・繋ぎ直している | 青（信号）の破線 |
| 再生中 | 青（信号）の実線の上を、小さな点が 2.4 秒で左から右へ流れる |
| 繋がらない（繋ぎ直しを待っている） | 赤（警告）の破線 |

- 動くのは再生中の点だけ。端末の設定で動きを切っている（アニメーションの速度が 0）ときは、点を流さず真ん中に止めて出す。

## 再生の画面

```
AudioSwitcher

PC ──────●────── この端末
192.168.11.5:48100

再生中
12:34

[          停止          ]   ← 再生中は枠線だけ、止まっているときは青い「再生」
接続先を変える
```

- **経過時間**（利用者と決めた）: 「再生」を押してから数える。繋ぎ直している間も数え続け、「停止」で消える。1時間未満は「分:秒」（5:07、23:45）、1時間以上は「時:分:秒」（1:23:45）。秒の境目ちょうどに書き換える。
  - 時刻は単調な時計（`SystemClock.elapsedRealtime`）で、再生サービスが「再生を押した時刻」を記録する（`PlaybackStartStore`）。画面を閉じて開き直しても、続きから出る。
- 接続先は普段は小さく出すだけで、「接続先を変える」を押したときだけ入力欄を出す。保存した接続先は、次に再生したときから使う（鍵は残す。docs/構成.md の 2.3）。

### 文字起こしの欄（再生の画面の下）

```
────────────────────────────
文字起こし                   [入/切]
保存先: Documents/SyncVault/30_Projects/Spaceまとめ
保存先を変える
文字起こし中: 2026-10-21 2010.md
前回 10/21 03:23 から 1時間2分: Groq Whisper 92%・端末の音声認識 8%、無料枠の上限 3回、切り替え 1回
Groq の1日の回数の上限が下がっています（2,000 → 1,000 回）   ← 下がったときだけ、赤
方式: 端末の音声認識
```

- 細い線（罫）で再生の部分と区切り、カードや影は使わない（目立たせるのは線だけ）。
- 入・切の切り替えは、信号の色で入を示す。保存先がまだ無いまま入にしたら、フォルダを選ぶ画面を開く（最初は `Documents/SyncVault/30_Projects/Spaceまとめ` を開く）。
- 今の状態（「文字起こし中: ファイル名」など）を出し、書けない・使えないなどの問題があれば赤（警告）で出す。
- 再生中に入・切を切り替えたり、保存先を選び直したりしたら、すぐ反映する。
- 前回の結果（方式ごとの時間の割合・無料枠の上限の回数・切り替えの回数）を、次に止めるまで残す（docs/構成.md の 2.5「無料枠の見張り」）。
- Groq の1日の回数の上限が下がったときは、赤（警告）で出す。
- 欄の下に「方式を変える」を置き、押すと方式の画面を開く。

### 方式の画面（文字起こしの欄の「方式を変える」から）

```
戻る
文字起こしの方式
優先度: Groq Whisper > Gemini > 端末の音声認識
選んだ方式で失敗が続いたら、優先度の順に下の方式へ切り替えて続け、10分ごとに選んだ方式へ戻して試します。Gemini の API キーが無ければ、Gemini は飛ばします。
────────────────────────────
(●) Groq Whisper
    Groq の無料枠で文字にします。送った音声は学習に使われません。API キーが要ります。
      API キー: 保存済み
      [ ●●●●●●●●           ]   キーを保存する  キーを消す
      モデルの名前
      [ whisper-large-v3-turbo ]  モデルの名前を保存する
────────────────────────────
( ) Gemini
    … 無料枠では、送った音声と結果が Google の改善に使われ、人が読むことがあります。…
────────────────────────────
( ) 端末の音声認識
    端末の中で文字にします。API キーは要らず、音声は端末の外に出ません。句点は付きません。
```

- 選んでいる方式にだけ、API キーとモデルの名前の欄を出す。
- API キーは伏せ字で入れ、保存したら画面には出さない（「保存済み」とだけ出す）。まだ無いときは赤で出す。
- Gemini の説明には、無料枠でのデータの扱いを必ず書く（選ぶときに分かるように）。
- モデルの名前は、英数字と「.」「-」「_」だけを受け付ける（URL に入れるため）。
- 戻るボタンと端末の「戻る」で、再生の画面へ戻る。

## ペアリングの画面

```
AudioSwitcher

（PC で解除されたときの知らせ。赤）

接続先（PC の IP:ポート）
[ 192.168.11.5:48100     ]

PC に出た数字と同じものを選んでください。
┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐
│12│ │47│ │80│ │03│ │66│
└──┘ └──┘ └──┘ └──┘ └──┘
残り 1:52
```

- 候補は同じ幅の四角いタイルを横一列に並べる。
- 残り時間は、PC のポップアップと同じく 2:00 から減る（外れて数字が作り直されたら、また 2:00 から）。
- 外れ・時間切れ・受け付けない状態などの知らせは赤（警告）で出し、PC で何をすればよいかを書く。
- 赤い知らせは同時に1つだけにする。「PC とのペアリングが解除されました」は、「ペアリングを始める」を押した時点で役目を終えるので消す（そのあとの外れなどの知らせと2つ並ばないように）。

## PC 側

常に出ている窓は無い。トレイのアイコンとメニューのほか、ペアリングの間だけ、画面右下に白基調のポップアップで数字を出す（docs/構成.md の 2.3）。
